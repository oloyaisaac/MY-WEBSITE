Why reversible matters

01

One-way redaction breaks the work

Scrub a customer email, ask “draft a reply”, and the model answers about [EMAIL_1]. Now you are hand-copying values back out of a spreadsheet. standin keeps the mapping so the reply is written to the real person, not to a placeholder.

02

Placeholders stay consistent

The same email is always [EMAIL_1], so the model can reason about “the same customer” across a long thread. New values get new numbers, and existing ones never shift.

03

Nothing is stored, sent or logged

No backend, no analytics, no third-party script, no “sign in to continue”. The page is static files and one JavaScript module — you can read all of it, or run it offline from a USB stick.

Same engine, in your terminal

The browser app is a thin shell over src/standin.js. The same rules run in Node with no dependencies, so you can scrub a log before pasting it — or wire it into a pipeline.

Verified detectors: Luhn for card numbers, mod-97 for IBANs, entropy + context checks for keys, and format-specific matchers for AWS, GitHub, Slack, Google, Stripe, JWTs and private keys. 

# scrub a file, keep the mapping
npx standin support-ticket.txt --vault vault.json

# paste the scrubbed text into your model, then put values back
npx standin reply.md --restore vault.json

# pipe it, or fail CI if something sensitive slips in
git diff | npx standin --check

Reasonable questions

Does this stop me from sending data to an AI provider?

No — you still choose what to send. standin reduces what the provider sees: it removes the identifiers that make text personal or dangerous to leak, and keeps enough structure for the model to do the work. You paste the scrubbed text into your model yourself.

Is this a compliance tool?

No. It is a careful pattern-and-checksum filter, not a data-loss-prevention product or a lawyer. It can miss context-dependent identifiers (unlabelled names, unusual ID formats) and it can over-redact. Read the diff before you send.

What about names, addresses and other free-text PII?

Those need language understanding, so they are behind an “experimental” switch and use conservative context patterns (“Regards, …”, “12 Kimball Street”). Expect misses; the toggle is off by default on purpose.

Can I use it as a library?

Yes: import { redact, restore } from './src/standin.js'. redact() returns { text, vault }; restore(text, vault) puts the real values back. MIT licensed, no dependencies, works in browsers and Node 18+.
